# 单包多级区域覆盖（Slice 36）

同一份 MBTiles 可以按不同区域保留不同 Zoom，例如：中国 Z5～10、业务省市 Z11～14、
任务区 Z15～18。每张瓦片属于所配置规则在该 Zoom 下的区域并集，重叠坐标只存一份。

## Windows 使用步骤

1. 在主面板选择卫星或矢量、是否合成中文注记，并填写 Token、输出目录和地图名称。
2. 将需要的全国、省市、自定义区域或任务航线缓冲区加入下载计划，逐条设置 Zoom，
   勾选启用。现有计划的分级推荐值可以继续使用，覆盖规则并不强制固定的 Zoom 分段。
3. 在下载计划「计划执行」区域点击「单包覆盖下载…（合并启用区域与各自 Zoom）」。
4. 后台生成边界快照和逐级并集，窗口显示规则清单、唯一瓦片数、请求数、容量预算、
   磁盘空间与具体输出文件。确认后创建一个任务，原有大任务风险确认照常执行。
5. 下载进度与暂停、继续、取消使用主窗口；程序重启后使用「下载任务」行上的「继续」。
   任务双击只提示其独立策略，不将它回填成可编辑的单区域矩形。
6. 完成后沿用「选择地图/检查/打包」流程生成带 manifest 的地图包。

「开始计划」继续按原方式生成多个独立文件。单包入口输出文件名包含覆盖策略指纹和
地图类型，例如 `<计划名>_coverage_<指纹前16位>_vec_cn.mbtiles`。
同一策略再次运行会补齐同一文件；修改范围、Zoom、名称或边界快照会生成新文件名，
原文件保留。卫星与矢量、是否合成注记分别命名，不混合坐标对应的不同图片。

首次生成单包不会自动复制此前独立下载的分包；预算会如实计算新单包的待下载量。
旧分包保留，可先评估请求量与容量再决定生成。当前功能是坐标覆盖合并，图片压缩、
跨文件内容去重和分包整理属于 Slice 38。

## 覆盖与性能规则

每条规则包含区域和 `[minZoom,maxZoom]`。按 Zoom 取启用规则后，先合并其瓦片行上的
X 区间，再用原有 Polygon 相交判定筛选。它不会遍历高 Zoom 下的全国总包围框，
也不会把全部期望坐标放进内存。相交区域不会重复排队、重复请求或重复计算进度。
全局下载速率、429 冷却与下载互斥沿用现有实现。

可以故意留空 Zoom，例如 Z5～10 概览加 Z15～18 任务区。未配置的级别期望数为 0；
高清任务区之外也不要求下载同级瓦片。检查器按规则验证，而不是按总 bounds 的矩形
计算覆盖率。中国与其他边界仍使用整张瓦片相交规则，边界瓦片可能包含境外像素。

这里只生成实际存在的瓦片。离线查看时的父级放大、缺图回退需要 Android Slice 39，
没有父级回退的客户端在未覆盖的高清区域仍可能显示空白。

## 策略快照、续传与包协议

首次生成时冻结规则使用的完整几何，规范 JSON 的 SHA-256 是策略身份。任务进度 JSON
只保存 `.coverage/<完整指纹>.json` 路径与身份，避免每次进度更新重写大量边界数据。
快照仅在确认下载后写入；预览和取消不会创建这些文件。

MBTiles 自带一份压缩的完整策略快照，不依赖原始 GeoJSON 路径或 Windows 区域目录。
若侧文件不存在而地图文件还在，续传可以从地图内置快照恢复。存在但损坏的侧文件会
明确报错，不能静默切换到其他边界。快照、任务身份或文件类型不一致时拒绝写入。

MBTiles 标准 `metadata` / `tiles` 表和 XYZ→TMS 写入方式保持一致。新扩展键：

- `region_type=coverage`、`region_id=coverage-<指纹前16位>`；
- `boundary_version=<完整 SHA-256>`；
- `coverage_data=<UTF-8 JSON 经 zlib 压缩后 Base64 编码>`，JSON 版本为 1；
- `manifest.region.coverage` 是不含完整几何的规则摘要，包含逐区 Zoom 与 bounds。

快照解析有版本、规则数量、有效多边形与大小限制。覆盖检查核对快照指纹、总范围和
Zoom 声明；坏策略报错，不按矩形猜测。打包再次校验 manifest 摘要与 MBTiles 快照。
旧单区域包不新增这些可选字段。

## 与容量预算联动

Slice 37 使用同一覆盖过滤器做逐级估算与已有瓦片扣除，只统计唯一坐标。预览包含
元数据和本地策略侧文件的磁盘空间，支持同盘完整打包副本预留。单包预览总会先展示，
即使关闭了其他下载的自动预算检查。空间不足不能继续，超预算可调整或明确继续。

整体降低最高 Zoom 的建议需要回到计划逐区域调整，单包窗口不会自动停用任务区。
预测期间改动计划条目、输出设置或主面板地图模式，会使旧结果失效。
